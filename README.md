# 🛒 Sistema Inventario Control

### Sistema Web de Gestión para Supermercados y Colmados

Aplicación Full Stack desarrollada con **Django REST Framework** y **Next.js** para administrar inventario, compras, ventas, clientes, proveedores y reportes.

🚧 **Estado del proyecto:** En desarrollo activo.

</div>

---

# 📖 Descripción

Sistema diseñado para digitalizar y optimizar la administración de supermercados, colmados y pequeños comercios.

Su objetivo es facilitar el control del inventario, reducir pérdidas, agilizar las ventas y proporcionar información en tiempo real para la toma de decisiones.

# ⚙️ Instalación

## Clonar el repositorio

```bash
git clone https://github.com/WirjinDaniel/Sistema-inventario-control.git
```

## Backend

```bash
cd Backend-app

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

## Frontend

```bash
cd control-web-app

npm install

npm run dev
```

# Sistema de Inventario Control

Sistema web para la gestión de inventario de supermercados y colmados.

## Funcionalidades

- Gestión de productos
- Gestión de categorías
- Control de inventario
- Compras y proveedores
- Ventas
- Dashboard con estadísticas
- Administración de usuarios y roles

## Tecnologías

### Backend
- Python
- Django
- Django REST Framework
- SQL Server

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- HeroUI

## Objetivo

Automatizar la administración de inventario y ventas, reduciendo errores y mejorando el control de existencias.
